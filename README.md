# Projeto: Livros da Bíblia

## Descrição

Este projeto foi desenvolvido como atividade acadêmica para praticar os conhecimentos básicos de HTML e CSS.

O site apresenta informações sobre a Bíblia e alguns de seus livros, utilizando páginas HTML e um menu para navegar entre elas.

## Páginas desenvolvidas

- **A Bíblia:** informações gerais sobre a Bíblia.
- **Gênesis:** criação do mundo e principais acontecimentos.
- **Êxodo:** história de Moisés e a libertação do povo de Israel.
- **João:** vida e ensinamentos de Jesus.
- **Apocalipse:** principais acontecimentos e mensagens do livro.

## Tecnologias utilizadas

- HTML5
- CSS3

## Organização do projeto

O projeto está dividido em duas pastas principais:

- `html`: contém as páginas do site.
- `css`: contém o arquivo responsável pela aparência das páginas.

## Como executar

Para visualizar o projeto, basta abrir o arquivo `a-biblia.html` em um navegador.

## Objetivo

O objetivo deste trabalho é colocar em prática os conceitos aprendidos em sala de aula, como a criação de páginas HTML, utilização de tags, links entre páginas e estilização com CSS.
